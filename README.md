# 🏆 FIFA World Cup 2026 – Fixture Viewer

An interactive group stage fixture viewer for the FIFA World Cup 2026.
Search any of the 32 teams or filter by group to see all their matches with Bangladesh time.

## 🔴 Live Site
👉 [View Fixtures](https://chyfarhanjamil.github.io/wc2026-fixtures/)

## ✨ Features
- All 32 teams across Groups A–L
- Search by team name instantly
- Filter by group (A to L)
- Match times in Bangladesh timezone (BST)
- Fully responsive — works on mobile and desktop
- No frameworks, no dependencies — pure HTML/CSS/JS

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript
- Hosted free on GitHub Pages

## 📋 Groups Covered
A · B · C · D · E · F · G · H · I · J · K · L
